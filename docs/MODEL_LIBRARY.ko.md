# 호환 모델팩

## 사용할 수 있는 범위

현재 실제 지원은 **일본어 → 한국어 / AIHub INT8, Beam 2**다. 홈의 원문·번역 언어 선택에는 설치된 실행 엔진이 지원하는 언어만 나타난다. 영어·중국어 등 다국어 번역 엔진·OCR을 추가한 상태가 아니다. 다른 언어를 지원하려면 해당 모델의 실행 방식, 토크나이저, 언어 코드, OCR까지 구현·검증해야 한다. 임의 GGUF·Safetensors·다른 구조의 ONNX는 내려받는 것만으로 실행되지 않는다.

기본 모델과 사전·일본어 OCR은 계속 APK에 포함한다. 최초 실행 때 다운로드하지 않아도 기존 번역을 사용할 수 있다. 다운로드 모델은 기본 MeCab/UniDic 사전을 공유하므로 별도 모델에 사전을 중복 설치하지 않는다. 모델 선택 시 저장한 선택을 다음 실행에도 사용하고, 번역 캐시는 모델을 바꾸면 지운다.

## 사용 흐름

1. 모델 탭에서 공개 GitHub 또는 Hugging Face 저장소의 첫 화면 주소를 입력한다.
2. **모델 확인**으로 지원 형식·방향·용량·라이선스를 확인한다. 모델 가중치는 아직 다운로드하지 않는다.
3. **다운로드**를 누르면 임시 폴더로 받아 각 파일의 크기와 SHA-256을 확인한다. 모두 완료돼야 설치 목록에 등록된다. 실패·취소 시 임시 파일을 삭제한다. 프로세스가 강제로 끝난 임시 파일은 다음 시작에 정리한다.
4. **선택·준비**를 누르면 해시 재검사, ONNX 입출력·토크나이저 검사와 내장 일본어 문장의 실제 추론을 실행한다. 형식 메타데이터가 맞아도 실행을 통과해야 선택이 저장된다. 이는 품질·지연·메모리 보장이 아니다.
5. 다운로드 모델은 확인 창을 거쳐 삭제할 수 있다. 선택한 모델을 삭제하면 기본 모델로 돌아간다. 기본 제공 모델은 삭제 대상이 아니다.

다운로드 중에는 진행률과 취소 버튼을 표시한다. 화면 번역 중에는 설치·모델 교체를 막는다. 공개 저장소만 지원하며 로그인 토큰·승인 필요 모델·이어받기는 구현하지 않았다. 큰 다운로드가 완료될 때까지 앱을 열어 두는 것을 권장한다. 앱 종료나 OS 프로세스 종료 시 이어받지 않고 다시 시작해야 한다.

HTTPS GitHub·Hugging Face 및 관련 다운로드 CDN만 허용하고, 리디렉션도 검증한다. 저장 공간·파일 크기·파일 이름·SHA-256을 검사하며 임의 경로나 실행 코드를 설치하지 않는다. 인터넷 권한은 모델 확인·다운로드에 필요하다. 캡처·OCR 원문·번역 요청을 전송하는 코드는 없고, 설치 후 번역은 오프라인이다. 외부 저장소의 해시는 게시자가 제공한 무결성 정보이므로 게시자 신뢰나 번역 품질까지 보증하지 않는다.

## 저장소 계약

공식 `https://huggingface.co/sappho192/aihub-ja-ko-translator` 주소는 내장 명세에 고정한 동일 모델 4개 파일을 찾는다. 이는 기본 모델을 다시 받는 기능 검사용이며 품질이 다른 모델이 아니다.

그 외 공개 저장소는 루트에 `lingolayer-model.json`이 있어야 한다. GitHub의 HEAD 또는 Hugging Face 저장소의 커밋 해시로 명세를 고정해 읽는다. 명세 안 파일 URL은 게시자가 불변 커밋/릴리스 주소로 지정한다. 루트의 [예제 명세](../lingolayer-model.json)는 기본 AIHub 파일을 가리키는 완전한 예제다. 호환 파인튜닝 모델을 배포할 때 해당 파일 URL·크기·해시·이름·라이선스로 교체한다.

GitHub에 큰 가중치를 일반 소스 파일로 넣을 필요는 없다. 명세에서 Hugging Face의 고정 커밋 다운로드 주소나 GitHub 릴리스 파일을 가리킬 수 있다. Git LFS 포인터 텍스트 자체를 모델 파일 URL로 주면 크기·해시 검사에서 거절된다.

- `format`: `lingolayer-model-v1`
- `engine`: `aihub-ja-ko-v1`
- `sourceLanguage` / `targetLanguage`: 현재 `ja` / `ko`
- `name`, `license`, `source`: 표시 이름·라이선스·공개 저장소 주소
- `files`: `encoder_model.onnx`, `decoder_model_merged.onnx`, `vocab.txt`, `tokenizer.json` 정확히 4개. 각각 `file`, `bytes`, 소문자 `sha256`, HTTPS `url` 필요

그래프는 기존 일본어 BERT + 한국어 KoGPT2의 ONNX 인코더/merged 디코더 구조, 입력·출력 이름과 캐시 텐서 규약, 원문 특수 토큰과 한국어 EOS 규약을 따라야 한다. 같은 `.onnx` 확장자만으로는 충분하지 않다. 외부 데이터 파일을 추가로 참조하는 모델은 이 4파일 형식에 해당하지 않는다. 팩 최대 2GiB, 어휘 파일 16MiB, 토크나이저 JSON 32MiB, 설치 모델 최대 16개를 허용한다.

기본 모델은 상위 모델 카드 MIT와 KoGPT2 CC-BY-NC-SA-4.0 고지를 함께 유지한다. 외부 모델의 라이선스와 원본 기반 모델의 조건도 각 게시자가 확인해야 한다. 소스 공개가 모델의 재배포·상업 사용 권한을 자동으로 부여하지 않는다.
