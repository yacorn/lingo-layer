# LingoLayer 베타 설치와 실행

버전 1.0.1-beta.1 (빌드 2). Android ARM64 기기용 비상업 평가 시제품입니다. 설치 가능한 최소 버전은 Android 8.0(API 26)이며 모든 지원 기기에서의 동작을 검증했다는 뜻은 아닙니다. 현재 검증된 번역 방향은 일본어→한국어입니다.

## 설치

1. 릴리즈 Assets에서 `LingoLayer-1.0.1-beta.1-arm64.apk`를 받습니다. 소스 ZIP은 설치 파일이 아닙니다.
2. `SHA256SUMS.txt`의 APK 해시와 비교합니다. Windows에서는 `Get-FileHash -Algorithm SHA256 -LiteralPath <APK 경로>`로 확인할 수 있습니다.
3. Android에서 APK를 열어 설치합니다. 브라우저나 파일 관리 앱에 이 출처의 앱 설치 허용이 필요할 수 있습니다.
4. 기존 LingoLayer와 서명이 다른 경우 업데이트가 거부될 수 있습니다. 기존 앱을 삭제하면 앱 설정·추가 모델 등 데이터가 삭제되므로 먼저 필요한 내용을 보관하세요.

APK에는 기본 번역 모델·사전·일본어 OCR이 들어 있습니다. 설치 외에도 첫 실행 시 기본 모델을 복사할 약 534MB와 준비용 여유 공간이 필요합니다. 현재 베타는 개발용 키로 서명하며 스토어 배포용 서명 체계를 제공하는 버전은 아닙니다.

## 기본 확인

직접 번역 탭에서 기본 일본어 예제를 번역하고, 같은 문장을 다시 번역해 결과 재사용 표시를 확인하세요. 이 기능은 화면 공유 없이 사용할 수 있습니다.

화면 번역은 다른 앱 위에 표시 권한과 사용자의 화면 공유 승인이 필요합니다. 자동 모드에서는 지원되는 Android 공유창에서 앱 하나를 고르고 번역할 앱을 선택합니다. 원문 변화에 따라 번역을 갱신하며 알림에서 일시정지·재개·종료합니다. 앱 하나 공유 기능은 Android 버전·기기 지원 여부에 따라 달라집니다. 수동 모드에서는 자동 번역을 끄고 떠 있는 버튼을 사용합니다.

기본 번역 범위는 화면 아래쪽으로 설정돼 있으므로 필요한 경우 번역 메뉴의 영역 선택으로 조정하세요. 원문 보기·복사·전체 번역 기능으로 OCR과 결과를 따로 확인할 수 있습니다.

## 범위와 고지

- 기본 엔진은 공개 AIHub JA→KO INT8 가중치와 Beam 2입니다. 번역 입력과 추론은 기기에서 처리하며 외부 번역 API를 사용하지 않습니다. 모델 다운로드와 ML Kit SDK 통계 통신은 별개입니다.
- 호환 모델팩을 확인·설치·선택·삭제할 수 있습니다. 모든 Hugging Face/GGUF 모델이나 모든 언어를 실행하는 기능은 아닙니다.
- OCR 누락·긴 글·세로쓰기·장식 글꼴·이름·은어·속담에 오류가 남아 있습니다. 보호된 앱 화면은 캡처할 수 없습니다.
- `THIRD_PARTY_NOTICES.md`와 앱 설정의 모델·엔진 라이선스에 출처 및 기반 라이선스를 제공합니다. AIHub 모델 카드의 MIT 표시가 기반 모델의 NC·SA 조건을 없앤다는 의미는 아닙니다. 상업 이용이나 모든 재배포 형태의 허용을 확인한 버전은 아닙니다.
- 이 릴리즈는 고지와 버전 정보를 갱신한 빌드입니다. 새로운 모델 가중치, OCR 개선 또는 실측 성능 향상을 주장하지 않습니다. 새 빌드 자체의 실기기 실행은 별도로 확인해야 합니다.
