# LingoLayer

Android 화면의 일본어를 기기에서 한국어로 번역해 원문 위치에 표시하는 Flutter 앱입니다. 외부 번역 API나 추론 서버를 사용하지 않습니다.

[베타 APK 다운로드](https://github.com/yacorn/lingo-layer/releases/tag/v1.0.1-beta.1) · [설치와 사용](docs/RELEASE_INSTALL.ko.md) · [빌드 안내](docs/BUILD.ko.md)

## 주요 기능

- 화면 변화에 따라 자동 번역하고, 테두리와 알림에서 실행 상태·일시정지·종료를 관리합니다.
- 수동 모드에서는 떠 있는 버튼을 눌러 번역합니다. 번역할 영역을 직접 지정할 수 있습니다.
- 긴 문단은 문장별로 순차 표시하며, 전체 번역과 OCR 원문을 따로 확인·복사할 수 있습니다.
- 직접 번역 탭에서 화면 공유 없이 문장을 입력해 번역합니다.
- 공개 GitHub·Hugging Face 저장소의 **호환 모델팩**을 확인·다운로드·선택·삭제합니다. [지원 형식](docs/MODEL_LIBRARY.ko.md)을 참고하세요.

## 지원 범위

현재 지원하는 번역 방향은 **일본어 → 한국어**이며, 기본 엔진은 **AIHub JA→KO INT8 + Beam 2**입니다. 언어 선택은 설치된 엔진이 지원하는 범위로 제한됩니다. 임의의 ONNX·GGUF·Safetensors 모델을 바로 실행할 수는 없습니다.

베타 APK는 Android 8.0(API 26) 이상 ARM64용입니다. 기본 모델·사전·일본어 OCR을 포함해 첫 실행 시 모델 다운로드가 필요하지 않습니다. 설치 외에 모델 복사본 약 534MB와 준비용 여유 공간이 필요합니다.

자동 모드는 지원되는 Android 공유창에서 **앱 하나**를 선택하는 방식을 권장합니다. 전체 화면 공유에서는 캡처 시 오버레이를 숨기는 과정에서 깜빡임이 발생할 수 있습니다. 화면 번역에는 다른 앱 위에 표시 권한과 사용자의 화면 공유 승인이 필요합니다.

## 제한과 개인정보

- OCR 누락, 긴 글·세로쓰기·장식 글꼴, 이름·은어·관용구의 번역 오류가 남아 있습니다. 보호된 앱·DRM 화면은 캡처할 수 없습니다.
- 번역 속도는 글의 길이와 기기 부하에 따라 달라집니다. GPU·NPU 가속은 적용하지 않았습니다.
- 캡처와 번역은 기기에서 처리하고 화면·OCR 원문을 파일로 저장하지 않습니다. 번역 캐시는 메모리에 유지합니다.
- 모델 확인·다운로드에는 인터넷을 사용합니다. ML Kit SDK는 성능·이용 통계를 전송할 수 있습니다. 오프라인 추론이 앱 전체의 통신 부재를 뜻하지는 않습니다.

## 개발과 고지

Flutter UI, Kotlin 화면 캡처·ML Kit OCR·오버레이, ONNX Runtime·MeCab 번역 엔진으로 구성됩니다. [빌드 안내](docs/BUILD.ko.md)에서 도구와 검증 절차를, [고정 모델 명세](models/manifest.json)에서 원본 리비전과 해시를 확인할 수 있습니다. 가중치·캐시·빌드 결과는 소스에 포함하지 않습니다.
